Zmey isn't downloadable yet. The apps are being built. Rather than a vague "coming soon," here's exactly where things stand.

01

What exists
right now.

The homeserver is live and running at zmey.chat. The infrastructure, client, and web repositories are all public. The encryption stack is integrated, the protocol works, the server accepts connections.

What's left is the client, the app you'd actually install on your phone or desktop. That's what's being built now.

live zmey.chat homeserver
public r16a-chat. Server infrastructure
public r16a-chat-client. Mobile app (in development)
public r16a-chat-web. Web client (in development)

02

Planned platforms.

iOS, Android, and desktop (Linux, macOS, Windows). Built from a single Flutter codebase, so all platforms ship together rather than staggered. No date commitment, but the plan is simultaneous release across all of them.
