# r16a-chat-web

Public-facing site for [Zmey](https://zmey.chat) — the info, trust, and download page for
[r16a-chat](https://github.com/Ramphy0x90/r16a-chat)'s self-hosted, end-to-end encrypted messaging
app.

---

## What it is

- Who's behind Zmey and why it exists
- Plain-language explanation of what's encrypted, what isn't, and what the operator can and can't see
- `security.txt` and vulnerability disclosure contact
- Warrant canary
- Links to the actual apps (once they exist)

## What it is not

- Not the web client. If a browser-based version of the app is ever built, it lives in
  [r16a-chat-client](https://github.com/Ramphy0x90/r16a-chat-client) as a Flutter web build target,
  not here.
- No user accounts, no data collection, no backend of any kind.
